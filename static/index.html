⏳ 回溯历史数据

对「历史 API 定时拉取」类型的机器，从选定起点到当前全量补拉历史并逐条入账。 已存在的数据按时间戳自动跳过、不覆盖——重复回溯只会补上次之后新增的， 全部已存在时结果就是「导入 0 条」，相当于提示无需回溯。
